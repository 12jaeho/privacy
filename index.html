개인정보처리방침

시행일: 2026년 10월 22일

이 문서는 채널 운영자가 자기 유튜브 채널에 영상을 올리기 위해 직접 만들어 쓰는 업로드 도구(이하 "이 앱")가 Google 사용자 데이터를 어떻게 다루는지 설명합니다. 이 앱은 일반 사용자에게 제공되거나 판매되지 않습니다.

1. 사용하는 데이터

이 앱은 Google OAuth로 로그인한 운영자 본인 계정에 대해 YouTube Data API의 youtube.upload 등 업로드에 필요한 권한만 요청합니다. 이 권한으로 하는 일은 운영자 본인 채널에 영상·썸네일·제목·설명을 올리는 것뿐입니다.

2. 데이터의 보관

로그인 결과로 받은 인증 토큰은 운영자 본인 컴퓨터에만 저장되며, 외부 서버로 보내지 않습니다. 이 앱은 시청자나 다른 사람의 개인정보를 수집하지 않습니다.

3. 제3자 제공

이 앱은 Google 사용자 데이터를 판매하거나 광고에 쓰거나 제3자에게 제공하지 않습니다. 이 앱의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회

언제든지 Google 계정의 서드 파티 연결에서 이 앱의 접근 권한을 삭제할 수 있습니다. 삭제하면 저장된 토큰은 더 이상 쓸 수 없습니다.

5. 문의

문의는 운영자 유튜브 채널의 정보(채널 정보 탭)에 안내된 연락처로 해 주세요.

Privacy Policy

Effective: October 22, 2026

This page explains how a private upload tool that a channel owner built and uses only for their own YouTube channels (the "App") handles Google user data. The App is not offered or sold to the public.

1. Data we use

The App asks the owner's own Google account, via Google OAuth, only for the YouTube Data API scopes needed to upload (such as youtube.upload). It uses them solely to upload videos, thumbnails, titles and descriptions to the owner's own channels.

2. Storage

The authorization token is stored only on the owner's own computer and is never sent to any other server. The App does not collect personal data about viewers or anyone else.

3. Sharing

The App does not sell Google user data, use it for advertising, or share it with third parties. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. Revoking access

You can remove the App's access at any time in your Google Account's third-party connections. Once removed, any stored token stops working.

5. Contact

Please use the contact information shown on the owner's YouTube channel (About tab).
